# Executive-Branch Trades — Open Dataset

**Every disclosed stock and asset transaction by senior US executive-branch officials — the President, Vice President, Cabinet, and senior appointees — parsed from their official OGE Form 278 and 278-T public financial disclosures.**

Congressional (STOCK Act) trading data has been open for years — this is the same thing for the executive branch. Executive officials file their transactions with the U.S. Office of Government Ethics (OGE) on Form 278e (annual/nominee reports, Part 7) and Form 278-T (periodic transaction reports). Those filings are public records, but they are published as individual PDFs, are not aggregated anywhere, and are **destroyed by law after 6–7 years** (5 U.S.C. app. § 105(d)). This repository is a machine-readable, permanently archived compilation of them, refreshed nightly.

- **Browse the data:** https://www.disclosedcapitol.com/executive
- **API access (free key, commercial use allowed):** https://www.disclosedcapitol.com/data-files/api

## Schema

| Column | Description |
|---|---|
| `filer_name` | Official's name as normalized by DisclosedCapitol |
| `role_title` | Role held on the transaction date (e.g. *Secretary of the Treasury*), from tenure records; falls back to the official's most recent role |
| `agency` | Department/agency for that role (empty for roles without one, e.g. President) |
| `ticker` | Ticker symbol. Pseudo-tickers (`BOND`, `MUNI`, `FUND`, `TREAS`, `LP`, `OPTION`, `TRUST`, `ETF`, `N/A`) are deliberate asset-class buckets for instruments without a public ticker — not errors |
| `asset_description` | Asset description as disclosed on the filing |
| `transaction_type` | Transaction type as disclosed (purchase / sale / exchange variants) |
| `transaction_date` | Transaction date (`YYYY-MM-DD`) |
| `amount_range` | Disclosed dollar range (OGE filings report ranges, not exact amounts) |
| `filing_date` | Date the filer signed the disclosure reporting this transaction |
| `filing_type` | `278` (annual/nominee report, Part 7) or `278-T` (periodic transaction report). Semicolon-joined when two same-day filings cannot be told apart |
| `source_filing_id` | OGE filing identifier linking the row to its source filing (semicolon-joined when ambiguous; empty when the source filing could not be resolved) |
| `disclosedcapitol_url` | The filer's DisclosedCapitol profile page |

## Provenance & methodology

- **Source documents:** official public OGE Form 278e / 278-T filings (oge.gov). Nothing in this dataset comes from any non-official source.
- **Parsing:** filings are parsed by [DisclosedCapitol](https://www.disclosedcapitol.com)'s ingestion pipeline — born-digital PDFs are parsed directly; scanned filings go through vision OCR with a machine-audit pass that checks extracted rows against the source document.
- **Traceability:** every row carries `source_filing_id` tying it back to its source filing; each official's DisclosedCapitol profile links the underlying .gov documents.
- **Faithful to the filings:** amounts are the disclosed ranges (executive filings do not report exact amounts), descriptions are as filed, and transactions that appear multiple times across filings reflect what was actually disclosed.
- **Export path:** `scripts/export.py` builds the dataset exclusively from DisclosedCapitol's public REST API (`/executive/officials`, `/executive/officials/{id}/profile`, `/politicians/{id}/trades`), so anyone with a free API key can reproduce it.

## Update cadence

Refreshed **nightly at ~10:00 UTC** by [GitHub Actions](.github/workflows/refresh.yml), after DisclosedCapitol's own overnight ingestion completes. A commit is made only when the data actually changed.
